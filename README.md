# 📝 Lock-In To-Do App

A clean and slightly unhinged To-Do List app built with JavaScript.  
Helps you lock in, get stuff done, and maybe gain some +1 aura along the way.

---

## 🚀 Features

- ➕ Add tasks  
- ❌ Delete tasks  
- ✅ Mark tasks as done  
- 🔄 Tasks persist (no vanishing after refresh)  
- ⚡ Smooth and instant UI updates  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript  

---

## 📌 About This Project

Started from a tutorial, but I didn’t just copy-paste and leave.  
Tweaked the UI, added persistence, and made it feel like an actual usable app.
